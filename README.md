<h2>📖 <b>About</b></h2>

<p>
Recipe Finder is a modern, full-stack mobile application that makes discovering and saving your favorite recipes effortless. 
Built with <b>React Native</b> and powered by a robust <b>Express backend</b>, this app provides a seamless cooking experience with beautiful UI, video tutorials, and personalized recipe collections.
</p>

<p>
Whether you're a beginner cook or a culinary expert, Recipe Finder helps you explore diverse cuisines, follow step-by-step instructions, and build your personal cookbook—all in one elegant interface.
</p>

<h2>✨ <b>Highlights</b></h2>

<ul>
  <li>🔐 <b>Secure Authentication</b> – Signup, Login, and 6-Digit Email Verification with Clerk</li>
  <li>🍳 <b>Featured Recipes</b> – Browse curated recipes and filter by categories</li>
  <li>🔍 <b>Smart Search</b> – Search recipes by name or ingredients</li>
  <li>🎥 <b>Video Tutorials</b> – Embedded YouTube guides</li>
  <li>❤️ <b>Favorites Collection</b> – Save recipes and access them anytime</li>
  <li>⚡ <b>Modern Tech Stack</b> – React Native + Express + PostgreSQL + Expo</li>
  <li>🆓 <b>100% Free</b> – Built entirely with free tools</li>
</ul>


<h2>🛠️ <b>Tech Stack</b></h2>

<b>Mobile App</b>
<ul>
  <li>React Native</li>
  <li>Expo</li>
  <li>Clerk Authentication</li>
  <li>React Navigation</li>
</ul>

<b>Backend</b>
<ul>
  <li>Node.js</li>
  <li>Express.js</li>
  <li>PostgreSQL (Neon)</li>
  <li>RESTful API</li>
</ul>

<h2>🚀 <b>Getting Started</b></h2>

<b>Prerequisites</b>
<ul>
  <li>Node.js (v16+)</li>
  <li>npm or yarn</li>
  <li>Expo CLI</li>
  <li>PostgreSQL database (Neon recommended)</li>
  <li>Clerk account</li>
</ul>
<h2>🖥️ <b>Run the Backend</b></h2>

<pre>
cd backend
npm install
npm run dev
</pre>

<h2>📱 <b>Run the Mobile App</b></h2>

<pre>
cd mobile
npm install
npx expo start
</pre>

<p>Scan the QR code with Expo Go or run on an emulator.</p>
